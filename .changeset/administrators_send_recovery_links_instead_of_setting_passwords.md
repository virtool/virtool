Administrators send recovery links instead of setting passwords

Administrators can help users recover access with a one-time link. They can no
longer set a user's password or require a password reset.

Users who had a pending required password reset have their password replaced
during the upgrade and are signed out. Users with a verified email address get
a password-changed notice. Send each affected user a recovery link so they can
set a new password.
