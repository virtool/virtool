Type to search the users and groups filters

When you open the **Users** filter on the samples and analyses lists, or the **Groups** filter on the samples list, the search box now has focus, so you can start to type immediately. The **Groups** filter now has a search box that finds groups by name. Use the up and down arrow keys to move through the list, and press Enter to add or remove the highlighted item. The first Escape clears the search, and the next Escape closes the filter.
