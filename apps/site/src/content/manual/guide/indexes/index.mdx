## Overview

Indexes are versioned snapshots of all the OTUs in a reference at points in time. In the background, indexes are
associated with optimized read mapping indices managed by Virtool.

When changes are made to OTUs, the index is rebuilt to include those changes in future analysis jobs. Each analysis is
tied to a specific index (version) of its target reference.

## View indexes

You can view the indexes that have been built for a specific reference

1. Click the **References** tab in the top navigation bar.

   Check the reference list to see what the latest built index is for the reference.

   The **Latest Build** box shows the latest index build. This index is used for any analyses started using that
   reference. In this example, the latest index is **Index 20**.

   ![References Overview Page](./reference_list.png?url)

2. Click the reference

   You can view the **Latest Index Build** for the reference you are using.

   ![Original Reference](./reference_latest.png?url)

3. Click the **Indexes** tab under the reference's name

   Here you see all the index versions for that reference. The top index is the latest version.

   ![Indexes Overview](./list.png?url)

## View a specific index

1. Click an index to view its details

   In this view, all the OTUs that changed and the contributors to those changes are visible.

   ![View Index 20](./detail.png?url)

2. Click the **Changes** tab

   Here all 259 changes are listed. The list shows all OTUs and what changes were made to them.

   ![Index Changes](./detail_changes.png?url)

## Build an index

When changes are made to a reference, a new index must be built before the changes are
used in analyses.

1. You see an alert in the **OTUs** and **Indexes** views when an index build is required

   ![Rebuild Index](./rebuild.png?url)

2. Click the <DummyLink>Rebuild the index</DummyLink>

   The **Rebuild Index** dialog appears and lists all the changes that are included in the index.

   ![Rebuild index dialog box](./rebuild_dialog.png?url)

3. To start making these changes and rebuilding the index, click <DummyButton icon="wrench">Start</DummyButton> on the
   bottom of the dialog box

   This starts an index build job.

   ![Start button to rebuild index](./rebuild_start.png?url)

4. Once the job is complete, there is a new index record marked <Icon name="check" /> **Active**.

   ![Version 1 index active](./rebuild_active.png?url)
