## Overview

A subtraction is a whole genome that Virtool uses to remove reads from analyses. Use it
for reads that are likely to come from the host, or from non-pathogenic organisms that
live on the host, such as insects or fungi.

To see your subtractions, click **Subtractions** in the main navigation bar. You can
search the list by name.

The subtraction pages are in the sidebar:

- **Browse**: the list of subtractions.
- **Files**: the FASTA files that you can use to make subtractions.

To create, edit, or delete a subtraction, you must have the `modify_subtraction`
[permission](/docs/guide/users#permissions).

## Upload a FASTA file

1. Get a FASTA file that contains the genome sequences.

   For example, you can download the
   [_Arabidopsis thaliana_ genome](ftp://ftp.ensemblgenomes.org/pub/plants/release-37/fasta/arabidopsis_thaliana/dna/).
   Make sure that the file includes the mitochondrial and chloroplast sequences.

2. Go to **Files**.
3. Drag the file onto the upload bar, or click **Browse Files** and select the file.

Virtool accepts plain or gzipped FASTA files that end in `.fa`, `.fasta`, `.fa.gz`, or
`.fasta.gz`. Your Virtool instance can set a maximum file size.

You must have the `upload_file` permission to upload files. To see the progress of an
upload, refer to [Track uploads](/docs/guide/samples#track-uploads).

## Create a subtraction

1. Go to **Browse**.
2. Click **Create**.
3. Type a **Name**.
4. Optional: type a **Nickname**. The nickname is an alternative name for the
   subtraction.
5. Under **Files**, select the FASTA file.
6. Click **Save**.

Virtool starts a Create Subtraction [job](/docs/guide/jobs). The list shows the
progress of the job beside the subtraction. When the job is complete, the progress
indicator goes away and you can use the subtraction.

If the job fails or is cancelled, the list shows **Failed** or **Cancelled** beside the
subtraction. You can't use this subtraction. Delete it and create a new one.

## View a subtraction

Click a subtraction in the list to see its details:

- **Nickname**: the alternative name of the subtraction.
- **File**: the FASTA file of the subtraction. Click the file name to download it.
- **Sequence Count**: the number of sequences in the subtraction.
- **GC Estimate**: the estimated GC content of the genome.
- **Linked Samples**: the number of samples that use this subtraction.

While the job runs, the page shows **Subtraction is still being imported**.

## Edit a subtraction

You can change the name and nickname of a subtraction.

1. Open the subtraction.
2. Click the pencil icon (**modify**) beside the name.
3. Change the **Name** or **Nickname**.
4. Click **Save**.

## Delete a subtraction

1. Open the subtraction.
2. Click the trash icon (**Delete**) beside the name.
3. Click **Confirm**.

Virtool removes the subtraction from the samples that use it. Analyses that already used
the subtraction keep their results.
