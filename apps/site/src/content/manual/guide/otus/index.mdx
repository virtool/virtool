## Overview

A reference is a collection of OTUs (organizational taxonomic units). Virtool uses the
OTUs in a reference to find pathogens in the sequencing data of your samples.

### Structure

An OTU usually represents one pathogen species.

Each OTU contains one or more _isolates_. An isolate is a strain, genotype, or variant
of the OTU. Each isolate contains one or more genome sequences.

An OTU must have at least one isolate, and each isolate must have at least one sequence.
If an OTU does not meet these conditions, Virtool shows a warning on the OTU. Virtool
does not include the OTU in the next index build until you correct the problems. In the
OTU list, these OTUs show **Unverified**.

### Isolate naming

An isolate name has two parts: the source type and the source name. This is similar to
how GenBank records store isolate information.

- The **source type** is the first word of the name. Examples are _isolate_, _strain_,
  _genotype_, and _variant_.
- The **source name** is the second part of the name. It identifies the isolate.

| Name             | Source type | Source name |
| ---------------- | ----------- | ----------- |
| Isolate A        | Isolate     | A           |
| Isolate Shenyang | Isolate     | Shenyang    |
| Variant B        | Variant     | B           |
| Genotype 6       | Genotype    | 6           |

If the source type is **Unknown**, the isolate has no name and shows as **Unnamed**.

A reference can restrict source types to a list. When it does, you select the source
type from that list. A user with permission to change the reference sets this list in
the reference **Settings**.

### Default isolate

Each OTU has one default isolate. Virtool uses the default isolate to represent the OTU
where it needs only one isolate. A star shows the default isolate in the isolate list.

The first isolate that you add to an OTU becomes the default. If you delete the default
isolate, another isolate becomes the default.

### Schemas

A schema defines the genome segments that each isolate of the OTU contains. For example,
a virus with two genome segments has two segments in its schema.

When an OTU has a schema, you can assign a segment to each sequence. This has these
effects:

- Sequences show in schema order in the sequence list.
- The sequence list shows the segment name of each sequence.
- Pathoscope labels coverage charts with the segment name, and shows the segments in the
  same layout for each isolate.

### Permissions

To change OTUs in a reference, you must have the **modifyOtu** right on that reference.
Without this right, you can view OTUs but the edit and delete buttons do not show.

You cannot change OTUs in an archived reference. The reference shows **Archived**.

### History

Virtool records each change to an OTU. Each record shows the OTU version, a description
of the change, the user who made it, and the time.

To see the history, open the OTU and click the **History** tab. Changes are in two
groups:

- **Unbuilt Changes**: changes since the last index build.
- **Built Changes**: changes that are in an index.

Changes to OTUs have no effect on analyses until you rebuild the index. When a reference
has unbuilt changes, the OTU list shows a link to **Rebuild the index**.

## Browse OTUs

1. Click **References** in the main navigation bar.
2. Click a reference.
3. Click the **OTUs** tab.
4. Click an OTU to open it.

To find an OTU, type its name or acronym in the search box.

An OTU has three tabs: **Isolates**, **Segments**, and **History**.

## Create an OTU

1. Go to the **OTUs** tab of the reference.
2. Click **Create**.
3. Type a **Name**. You can also type an **Acronym**.
4. Click **Save**.

The name and the acronym must be unique in the reference.

A new OTU has no isolates. Add an isolate and a sequence before you build an index.

## Edit an OTU

You can change the name and acronym of an OTU.

1. Open the OTU.
2. Click **edit OTU** beside the OTU name.
3. Change the **Name** or **Acronym**.
4. Click **Save**.

## Delete an OTU

1. Open the OTU.
2. Click **Delete** beside the OTU name.
3. Click **Confirm**.

Rebuild the index to remove the OTU from future analyses.

## Add an isolate

1. Open the OTU.
2. On the **Isolates** tab, click **Create**.
3. Enter a **Source Type** and a **Source Name**.

   The **Isolate Name** field shows the name that Virtool makes from these two values.

4. Click **Save**.

## View an isolate

On the **Isolates** tab, click an isolate to open it. The isolate page shows its
sequences.

To find an isolate, type in the search box. You can search by source name, sequence
accession, or sequence definition.

## Edit an isolate

1. Open the isolate.
2. Click **edit name**.
3. Change the **Source Type** or **Source Name**.
4. Click **Save**.

## Set the default isolate

1. Open the isolate.
2. Click **set as default**.

This button does not show on the isolate that is already the default.

## Delete an isolate

1. Open the isolate, or find it in the isolate list.
2. Click **Delete**.
3. Click **Confirm**.

## Add a sequence

1. Open the isolate.
2. Click **Create Sequence**.
3. Complete the fields:

   - **Segment**: the schema segment that the sequence represents. This field shows only
     when the OTU has a schema. Each segment can be assigned to only one sequence in an
     isolate.
   - **Accession (ID)**: required.
   - **Host**: optional.
   - **Definition**: required.
   - **Sequence**: required. The sequence can contain only the characters `ATCGNRYKM`.

4. Click **Save**.

To get data from GenBank, type a GenBank accession in **Accession (ID)** and click
**Auto Fill**. Virtool fills the accession, host, definition, and sequence. Make sure
the values are correct before you save.

## View a sequence

The sequence list shows the accession, segment, and definition of each sequence. Click a
sequence to show its host and full sequence.

## Edit a sequence

1. Open the isolate.
2. Click the sequence to expand it.
3. Click **Edit**.
4. Change the fields.
5. Click **Save**.

## Delete a sequence

1. Open the isolate.
2. Click the sequence to expand it.
3. Click **Delete**.
4. Click **Confirm**.

## Export sequences

You can copy or download the sequences of an OTU or an isolate.

- To export from the OTU, go to the **Isolates** tab and click **Export**.
- To export from one isolate, open the isolate and click **Export**.

By default, the export includes all the items in the list. To export only some items,
select their checkboxes first. To select a range, hold **Shift** and click a second
checkbox. In the isolate list, the export includes only the isolates that match your
search.

The **Export** menu has these items:

- **Accessions**: a list of sequence accessions.
- **FASTA**: the sequences in FASTA format.
- **Sequence table**: one row for each sequence.
- **Isolate table**: one row for each isolate. This item shows only for an OTU export.

Under **Copy**, click an item to copy it to the clipboard. Copied tables are TSV, so
they paste into a spreadsheet as columns. Under **Download**, click an item to download
it as a file.

You can also select the **FASTA header** and the **Table download format** in the menu.
These choices apply until you leave the page. To change the defaults, click **Settings**
in the menu, or see [Account](/docs/guide/account).

## Add a segment

1. Open the OTU.
2. Click the **Segments** tab.
3. Click **Create**.
4. Type a **Name**. Each segment in the schema must have a unique name.
5. Select a **Molecule Type**, or leave it as **None**.
6. Select **Required** if each isolate must contain this segment. Clear it if the
   segment is optional.
7. Click **Save**.

The segment list shows **Required** or **Optional** for each segment.

## Edit a segment

1. Open the OTU.
2. Click the **Segments** tab.
3. Click **edit segment** on the segment.
4. Change the fields.
5. Click **Save**.

## Assign a segment to a sequence

1. Add the segments to the schema of the OTU. See [Add a segment](#add-a-segment).
2. Open an isolate.
3. Click a sequence to expand it, then click **Edit**.
4. Select a segment in the **Segment** field.

   The list shows only the segments that no other sequence in the isolate uses.

5. Click **Save**.

When you assign a segment to each sequence, the sequence list shows the sequences in
schema order.

## Reorder a schema

1. Open the OTU.
2. Click the **Segments** tab.
3. Drag a segment by its **drag to reorder** handle to a new position.

Virtool saves the new order immediately. The sequence lists of all isolates in the OTU
use the new order.

## Delete a segment

1. Open the OTU.
2. Click the **Segments** tab.
3. Click **Delete** on the segment.
4. Click **Confirm**.
