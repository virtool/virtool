## Overview

A job is a long-running task that processes bioinformatic data.

| Type               | Description                                                                           |
| ------------------ | ------------------------------------------------------------------------------------- |
| Create Sample      | Creates a sample from uploaded FASTQ files.                                           |
| Create Subtraction | Creates a subtraction from an uploaded FASTA file.                                    |
| Nuvs               | Runs a Nuvs analysis for a sample and a reference.                                    |
| Pathoscope         | Runs a Pathoscope analysis for a sample and a reference.                              |
| Build Index        | An older job type that built a reference index. Virtool doesn't start these jobs now. |

Virtool starts a job when you start a task in a different part of the app, for example
when you create a sample. A new job waits in a queue until a runner is available.

A job has one of these states:

- **Pending**: the job waits for a runner.
- **Running**: a runner does the job.
- **Succeeded**: the job is complete.
- **Failed**: the job stopped because of an error. Virtool also marks a running job as
  failed when its runner stops responding for more than five minutes.
- **Cancelled**: the job stopped before it was complete.

## List jobs

Click **Jobs** in the main navigation bar. The list shows the running jobs.

Each job shows its type, the user who created it, when it was created, its state, and its
progress.

To show jobs in other states, select or clear the states under **State**. Each state
shows the number of jobs in that state.

## View a job

Click a job in the list to see its details.

For a Create Sample, Create Subtraction, Nuvs, or Pathoscope job, the page shows the
sample, subtraction, or analysis that the job makes. Click its name to open it.

The page also shows the steps of the job. Each step shows its name, a description, when
it started, and how long it took. The current step shows a spinning icon.

If no step has started, the page shows the state of the job. A pending job shows
**Waiting for a runner**.
