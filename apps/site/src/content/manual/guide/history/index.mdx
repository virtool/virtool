## Overview

History refers to the tracked changes made to OTUs. When any aspect of an OTU is changed, a history _change_ record is created.

Changes can be considered in different contexts. One is at the OTU-level, where the changes describe the entire life of that OTU record. Changes can also be considered as a descriptor of indexes. An index can be thought of as a collection of changes to a selection of OTUs.

## View OTU changes

The example below uses Abaca Bunchy Top Virus (ABTV).

1. Navigate to the detail view for an OTU

   ![Detail view for ABTV](./abtv_detail.png?url)

2. Click the **History** tab

   This shows all changes ever made to the OTU.

## View index changes

1. Navigate to the detail view for a reference

   ![Reference Detail](./ref.png?url)

2. Click the **Indexes** tab to list the indexes for the reference

   ![Reference Indexes List](./index_list.png?url)

3. Click an index

   Index **Version 20** was selected. The index detail page provides an overview of the changes included in the index.

   ![Index Detail](./index_detail.png?url)

4. Click the **Changes** tab

   This view shows an exhaustive list of all changes made on each OTU in the index.

   ![Detailed Index Change List](./index_changes.png?url)

## Revert changes

You can revert any **unbuilt** changes made to an OTU.

Changes included in a complete index build can't be reverted, so it's a good idea to be certain of any changes before starting an index build.

1. Navigate to the detail page for an OTU

   Note that the OTU has one isolate called _Isolate Q768_.

   ![OTU Detail Page](./abtv_detail_old.png?url)

2. Click the **History** tab to view the history for the OTU

   The history shows this OTU came from another reference, then one of its isolates was removed (_Q1108_) and the other was renamed from _Q767_ to _Q768_.

   ![OTU History Page](./abtv_history_before.png?url)

3. Click the <Icon name="history" color="blue" /> icon to revert a change

   Any succeeding changes are also removed.

   <video src="./revert.mp4" alt="Revert a change" autoplay />

4. Navigate back to the **OTU** tab

   The reversions are reflected in the OTU data. In this example, the previously removed isolate (_Q1108_) is restored and the other isolate (_Q767_) has its previous name back.

   ![OTU with Reverted Changes](./abtv_detail.png?url)
