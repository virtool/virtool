## Overview

A reference is a collection of pathogens, their isolates, and their genome sequences.
Virtool uses a reference to find pathogens in the reads from your samples.

You must have at least one reference with OTUs and a built index before you can analyze
samples.

### OTUs

In Virtool, pathogen records are called OTUs (operational taxonomic units). Usually, one
OTU is one pathogen species. You decide how to organize the OTUs in your reference.

Virtool records each change to an OTU. See [OTUs](/docs/guide/otus).

### Indexes

An index is a versioned snapshot of all the OTUs in a reference. Each analysis uses one
index of its reference.

When you change OTUs, you must build a new index before analyses can use the changes.

### Access

These users can see a reference:

- The user who created the reference.
- Users and groups that are added to the reference.
- Full administrators.

To create a reference, you must be an administrator or have the **create_ref**
permission.

## Find a reference

1. Click **References** in the main navigation bar.
2. Type a name in the **Reference name** search field.
3. Click a reference to open it.

The list shows active references. To see archived references, click **Archived**.

## Reference detail

A reference has these tabs:

- **Manage**: the description, the organism, the source reference of a clone, the latest
  index build, and the contributors.
- **OTUs**: the OTUs in the reference. See [OTUs](/docs/guide/otus).
- **Indexes**: the index builds of the reference.
- **Settings**: source types, users, and groups.

## Create an empty reference

1. Go to **References**.
2. Click **Create**.
3. Under **Method**, select **Empty**.
4. Type a **Name**.
5. Optionally, type an **Organism** (for example, virus) and a **Description**.
6. Click **Create**.

The new reference has no OTUs. You become a member of the reference with all rights.

## Import a reference

You can import a reference file from another Virtool instance. The file name must end in
`.json.gz` or `.v1.sqlite.gz`.

1. Go to **References**.
2. Click **Create**.
3. Under **Method**, select **Import**.
4. Drag the reference file to the upload area, or click **Browse Files** to select it.
5. Type a **Name** and, optionally, a **Description**.
6. Wait for the upload to finish. Refer to
   [Track uploads](/docs/guide/samples#track-uploads).
7. Click **Create**.

The reference appears in the list. A progress circle shows the progress of the import.
The upload size limit of your Virtool instance applies to the file.

## Clone a reference

A clone is a copy of a reference. You can change the clone and the original does not
change.

1. Go to **References**.
2. Click **clone** beside the reference that you want to copy.
3. Change the **Name** if necessary. The default name is "Clone of" followed by the name
   of the source reference.
4. Click **Clone**.

The clone appears in the list. A progress circle shows the progress of the copy.

The clone gets the organism of the source reference. Its **Manage** tab shows a link to
the source reference.

You can't clone an archived reference.

## Edit a reference

You must have the **modify** right on the reference.

1. Open the reference.
2. Go to the **Manage** tab.
3. Click **modify**.
4. Change the **Name**, **Organism**, or **Description**.
5. Click **Save**.

You can't edit an archived reference.

## Archive a reference

Archive a reference that you no longer use. You must have the **modify** right on the
reference.

1. Open the reference.
2. Go to the **Manage** tab.
3. Click **archive**.
4. Click **Archive** to confirm.

An archived reference:

- Does not show in the default reference list.
- Can't be edited, and its OTUs can't be changed.
- Can't be used for new analyses.

Existing analyses that use the reference stay available.

To make an archived reference active again, open it, click **unarchive**, and then click
**Unarchive**.

## Indexes

### View indexes

Go to the **Indexes** tab of a reference. The list shows the version of each index and
the number of changes and OTUs that each build includes.

The index that analyses use is marked **Active**. An index that is still being built is
marked **Building**.

The **Manage** tab shows the latest index build.

### View an index

Click an index in the list. The index page shows:

- **Contributors**: the users that made the changes in the index.
- **Files**: the data files of the index. Click a file name to download the file.
- **OTUs**: the OTUs in the index.

### Build an index

You must build a new index before analyses can use changes to OTUs. You must have the
**build** right on the reference.

When the reference has unbuilt changes, the **OTUs** tab shows an alert.

1. Go to the **Indexes** tab.
2. Click **Create**.

   The **Rebuild Index** dialog shows the changes that the new index includes.

3. Click **Start**.

Virtool starts a job that builds the index. When the job is complete, the new index is
marked **Active**.

The **Create** button shows only when the reference has unbuilt changes. You can't build
an index for an archived reference.

## Source types

An isolate name has a source type and a source name, for example _isolate A_. You can
limit the source types that users can select for isolates in a reference.

You must have the **modify** right on the reference.

1. Open the reference.
2. Go to the **Settings** tab.
3. Select **Restrict Source Types**.

When this setting is off, users can type any source type.

### Add a source type

1. Type the source type under **Add Source Type**.
2. Click **Add**.

A source type can't contain spaces. Virtool changes it to lowercase.

### Remove a source type

Click **Remove** beside the source type. To add it again, click **undo**.

### Default source types

A new reference gets the default source types. To change the defaults, you must be a
full administrator.

1. Go to **References**.
2. In the sidebar, click **Settings**.
3. Add or remove source types under **Default Source Types**.

A change to the defaults does not change existing references.

## Users and groups

Users and groups that you add to a reference can see the reference and use it in
analyses. You can give them more rights.

To manage users and groups, you must have the **modify** right on the reference. Go to
the **Settings** tab of the reference.

### Add a user or group

1. Click **Add user** or **Add group**.
2. Type in the search field to find the user or group.
3. Click the user or group.

A new user or group has no rights.

### Change rights

1. Click **edit member** beside the user or group.
2. Select the rights that you want to give:

   - **modifyOtu**: change the OTUs in the reference.
   - **build**: build new indexes for the reference.
   - **modify**: change the reference properties and settings.

Virtool saves each change immediately.

A user gets the rights of all their groups in addition to their own rights.

### Remove a user or group

Click **Remove member** beside the user or group. Virtool removes the user or group
immediately and does not ask you to confirm.
