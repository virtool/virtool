Pathoscope is a workflow that finds known reference OTUs in an Illumina sample library.

## How does it work?

Pathoscope maps sample reads to a Virtool reference. It counts the reads that match each
OTU and uses these counts to get a detection result. To understand this section, you
must know about [references](/docs/guide/references) and [OTUs](/docs/guide/otus).

Before Pathoscope maps the reads, it collapses redundant isolates in the reference.
Isolates of an OTU frequently have only a small number of different bases. Pathoscope
uses [CD-HIT-EST](https://github.com/weizhongli/cdhit) to put the isolate sequences into
clusters at 99% identity (Li & Godzik, 2006; Fu et al., 2012). When two isolates of an
OTU have the same cluster representatives, Pathoscope keeps only the first isolate. All
of the mapping steps use this collapsed reference.

In the first mapping step, Pathoscope uses
[Bowtie 2](https://bowtie-bio.sourceforge.net/bowtie2) to map sample reads to the
_default_ isolates of all OTUs in the target reference (Langmead & Salzberg, 2012). This
step is a prescreen. It finds the OTUs that are possibly in the sample. Pathoscope keeps
each OTU that has one or more matching reads as a candidate hit for the second step.

In the second step, Pathoscope makes a Bowtie 2 mapping index. This index contains all
isolates of the OTUs that the _default_ isolate mapping found. Thus, each virus has more
different mapping targets, and Pathoscope can find viruses at the isolate level.

Next, Pathoscope removes reads that come from the host. It maps the remaining reads to
each [subtraction](/docs/guide/subtractions) that you select for the analysis. If a read
aligns to a subtraction as well as or better than it aligns to an OTU, Pathoscope
removes that read. Thus, host sequences that are similar to viral sequences do not cause
false detection results.

A major problem with this diagnostic method is multi-mapping. Multi-mapping occurs when
one read aligns to more than one position in the reference sequences. A sample can
contain only a small number of true source sequences. But the reads from one source can
align to many locations in the Virtool reference. This occurs most frequently when an
OTU contains many similar isolates.

Pathoscope uses an expectation maximization (EM) algorithm to reassign multi-mapped
reads to their most probable source sequences (Francis et al., 2013; Hong et al., 2014).
Pathoscope assumes that source sequences with many **uniquely mapped** (not
multi-mapped) reads are most probably real source sequences. When a read maps to more
than one genome, Pathoscope divides the read count between those genomes.
