Nuvs is a workflow that finds possible novel viral sequences in a sample library.

## How does it work?

Pathoscope finds known viruses when it maps reads to reference sequences. Nuvs uses a
different method. It assembles the reads that do not match the reference. Then it uses
profile hidden Markov models (HMMs) to find viral domains in the assembled sequences.
Thus, Nuvs can find divergent viral sequences that mapping or the Basic Local Alignment
Search Tool (BLAST) possibly cannot find.

First, Nuvs uses [Skewer](https://github.com/relipmoc/skewer) to trim the sample reads
(Jiang et al., 2014). Skewer removes reads with an average quality score of less
than 25. For paired libraries, it removes a pair only if the two reads both have an
average quality score of less than 25.

Then Skewer removes Illumina adapter sequences from the reads. It also removes bases
from the 3' end of each read until it finds a base with a quality score of 20 or more.

Then Skewer removes reads that are too short. For paired libraries, if one read is too
short, Skewer removes the two reads. The minimum length changes with the length of the
longest read in the sample:

| Longest read | Minimum length |
| ------------ | -------------- |
| Less than 80 | 35             |
| 80 to 159    | 100            |
| 160 or more  | 160            |

Pathoscope does not trim reads.

Next, Nuvs removes reads that match known OTUs or a host genome. First, it maps the
reads to a Virtool reference and removes all reads that match. Then it maps the
remaining reads to each host subtraction genome and removes the reads that match. For
paired libraries, Nuvs keeps a read only if it also keeps the mate of that read.

Nuvs then uses [SPAdes](https://ablab.github.io/spades) to assemble the remaining reads
into contigs (Bankevich et al., 2012).

Next, Nuvs finds open reading frames (ORFs) in the contigs. It keeps only ORFs of 100 or
more amino acids. It removes contigs shorter than 300 bases and contigs that have no
ORFs. These contigs do not show in the results.

Finally, Nuvs compares the translated ORFs with the installed profile HMMs.

## HMMs

Virtool uses profile HMMs to find possible novel viruses in sequencing data. The models
find known viral motifs in translated open reading frames from sequencing data.

[HMMER](https://hmmer.org) compares these models with translated ORFs (Eddy, 2011). The
models come from clustered amino acid sequences in GenBank.

Virtool supplies an official set of models that come from the
[vFam](https://derisilab.ucsf.edu/software/vFam/) project (Skewes-Cox et al., 2014).
These models do not have biological annotations. Thus, Virtool also supplies
annotations. Virtool calculates these annotations from the metadata of the amino acid
sequences that are the source of the models.

To install and manage HMMs, see the [HMMs guide](/docs/guide/hmms).

## Interpret results

An HMM match does not prove that a contig comes from a novel virus. To compare a contig
with known sequences, use [BLAST](/docs/guide/analyses#blast). To read and understand
Nuvs results, see [Interpret Nuvs](/docs/guide/analyses#interpret-nuvs) in the analyses
guide.
